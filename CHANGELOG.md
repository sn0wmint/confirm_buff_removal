# Changelog

All notable changes to Confirm Buff Removal are listed here, newest first.
Version numbers follow [Semantic Versioning](https://semver.org/).

## 1.0.0 - 2026-11-20

First release.

- Right-clicking one of your buffs asks for confirmation before removing it.
- In combat, Accept unlocks that buff for 5 seconds, and a second right-click removes it.
- Druid forms, Stealth and Shadowform always use the second right-click, because the game never lets addons remove them.
- Hovering a protected buff still shows its tooltip.
- Buffs in the consolidated-buffs pop-out are protected too.
